# Canis Aluguel

Bem-vindo ao Canis, uma página desenvolvida para promover e facilitar o aluguel de hospedagens na cidade de Cananéia. Este projeto apresenta informações detalhadas sobre as estadias disponíveis, seus benefícios e formas de contato para reservas.

# 📋 Descrição

A página foi projetada para oferecer uma experiência intuitiva e visualmente agradável aos usuários que desejam alugar hospedagens em Cananéia. Ela inclui:

## Galeria de Imagens: Fotos das acomodações e paisagens locais.

- Descrição das Propriedades: Informações detalhadas sobre as estadias, como localização, comodidades e capacidade.

- Benefícios: Destaques das vantagens de se hospedar em Cananéia.

- Contato: Links diretos para WhatsApp, QR Code para pagamento e informações de Pix.

- Responsividade: Layout adaptado para dispositivos móveis e desktops.

## 🛠️ Tecnologias Utilizadas

- HTML5: Estrutura da página.

- CSS3: Estilização com arquivos como global.css, style.css e modal.css.

- Bootstrap 5: Framework para responsividade e componentes visuais.

- LightGallery.js: Biblioteca para exibição de imagens em formato de galeria.

- JavaScript: Funcionalidades interativas, como modais e filtros de galeria.
